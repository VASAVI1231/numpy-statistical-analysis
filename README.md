# NumPy Statistical Analysis

## Internship Task 15 – AI & ML Track

### Project Overview

This project performs statistical analysis on student performance data using Python and NumPy.

The dataset is created directly inside the Python program using NumPy arrays. Therefore, no external CSV file is required.

The project calculates descriptive statistics, compares subject performance, identifies the highest and lowest performing students, and checks for potentially unusual values.

## Objectives

- Calculate mean
- Calculate median
- Calculate standard deviation
- Find minimum and maximum values
- Calculate range
- Calculate student total and average
- Identify highest and lowest performing students
- Compare subject-wise performance
- Detect potentially unusual values

## Technologies Used

- Python
- NumPy
- Google Colab
- GitHub

## Dataset

The project uses student marks for three subjects:

- Math
- Science
- English

The dataset contains 12 students and is created directly inside the Python program using NumPy arrays.

No CSV file or external dataset is required.

## Statistical Functions Used

### np.mean()

Calculates the arithmetic average of the values.

### np.median()

Finds the middle value of the dataset.

### np.std()

Calculates the standard deviation and measures the spread of the data.

### np.min()

Finds the minimum value.

### np.max()

Finds the maximum value.

### np.ptp()

Calculates the range between the maximum and minimum values.

### np.sum()

Calculates the total of the values.

### np.argmax()

Finds the position of the largest value.

### np.argmin()

Finds the position of the smallest value.

## Methodology
1. Create student performance data using NumPy arrays.
2. Combine the subject scores into a NumPy matrix.
3. Calculate subject-wise statistical measures.
4. Calculate overall statistics.
5. Calculate total and average marks for each student.
6. Identify the highest and lowest performing students.
7. Compare subject-wise averages.
8. Check for unusual values using mean ± 2 standard deviations.
9. Display the final analysis.
